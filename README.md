# 🎲 Sorteador de Números

Um projeto simples em JavaScript para gerar números aleatórios dentro de um intervalo definido pelo usuário, com opção de repetição ou não.

---

![Preview do projeto](./assets/images/projeto1.png)

## 🚀 Funcionalidades

- Gerar números aleatórios entre um valor mínimo e máximo
- Definir a quantidade de números a serem sorteados
- Opção de permitir repetição ou não
- Validação de entradas do usuário
- Exibição dinâmica dos resultados na tela

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (opcional)
- JavaScript (ES6+)
